Paramètres

Seuils de l'analyse — pris en compte sans redémarrage

arret_auto_seuil_s
Sans cycle pendant N secondes => arrêt non planifié détecté
derive_courant_pct
Dérive du courant moteur vs baseline (%) => usure probable
tarif_kwh
Tarif électrique moyen STEG (TND/kWh) — pour coût énergie / coût par pièce
temp_palier_max_c
Température palier max avant alerte surchauffe
tension_max_v
Tension maxi avant alerte surtension (V) — 400V triphasé +10%
tension_min_v
Tension mini avant alerte sous-tension (V) — 400V triphasé −10%
tnenergy_base_url
URL API TNEnergy (optionnel) — sinon conso calculée localement via PZEM
trs_cible_pct
TRS cible du client (référence tableau de bord)
vibration_alerte_mm_s
Seuil vibration RMS (ISO 10816) au-delà = alerte
watchdog_offline_min
Boîtier sans mesure depuis N minutes => hors ligne
